# Repository guidance

Implement executable behavior with meaningful tests. Do not fabricate data, metrics,
training success or hardware results. Keep torch optional for ordinary CPU OCR.
Preserve Unicode marks; document normalization and page/line distinctions.
Run ruff and pytest after code changes. Use synthetic fixtures for mechanics only.
Do not import private code or commit credentials, raw datasets or checkpoints.
Work on feature branches; review public content before committing or publishing.
